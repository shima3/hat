空リストの判定


sample3.schの右のRunボタンを押して実行してください。 Terminal:の下の枠内に真, A, B, 偽という4行を表示します。
13行目のisNilでnilがnilかどうかを判定し、もちろんnilなので13行目を実行し、「真」と表示します。 16行目で2つの要素"A", "B"からなるリストを変数listに代入します。 17行目でlistPrintを呼び出します。 18行目のisNilでlistがnilかどうかを判定し、nilではないので19行目を実行し、「偽」と出力します。
listPrintは4〜10行目で定義されています。 6行目のisNilでlistがnilかどうかを判定し、nilならばreturnを呼び出して戻ります。 nilでなければ7〜10行目を実行します。 7行目のgetFirstでlistの先頭の要素を取得し、8行目のprintで出力します。 9行目のgetRestでlistの先頭を除く残りのリストを取得し、10行目のlistPrintで出力します。 理解を確かめるため、リストの要素を3個とし、各要素を表示するように変更してみてください。

高階関数 reduce

高階関数 map


sample5.schの右のRunボタンを押して実行してください。 Terminal:の下の枠内に4, 9, 16という3行を表示します。
17行目で3つの数値2, 3, 4からなるリストを変数listに代入します。 18行目で関数squareとそのリストを関数mapに渡します。 mapはリストの各要素をsquareに渡した結果のリストを返します。 squareは4〜6行目で定義されていて、与えられた数値xの2乗を返します。 理解を確かめるため、3乗を表示するように変更してみてください。

mapの遅延評価


sample6.schの右のRunボタンを押して実行してください。 Terminal:の下の枠内にmainやsquareで始まる行と4, 9, 16という行を表示します。
sample5.schの実行順序を確かめるため、printを挿入したものです。 mainで始まる行は19, 21, 23行目のprintで表示されます。 squareで始まる行は6行目のprintで表示されます。
main 2を表示する前に、squre x=2は表示しています。 しかし、squre x=3とsqure x=4はmain 2を表示した後に表示しています。 これは、20行目ですべて計算せず、22行目で表示するときに遅延評価するからです。

三目並べの局面


sample7.schの右のRunボタンを押して実行してください。 Terminal:の下の枠内に、mainで始まる行、三目並べの盤面、Turn:で始まる行を表示します。
sample7.schの13行目でinitPosition関数を呼び出し、局面を変数pに代入します。 局面とは、盤面と次の手を打つのが誰の番かを示すものです。 第1引数は9文字の文字列で盤面のマルとバツを示します。 最初の3文字が1行目、次の3文字が2行目、最後の3文字が3行目に対応します。 第2引数"X"は、次がバツの番であることを意味します。 sample7.schの15行目でprintPosition関数を呼び出し、最初の局面pを表示します。 printPosition関数は、縦棒、マイナス、プラスの文字を使って盤面を示し、Turn:で始まる行で次の番がマルかバツかを示します。 この例では、initPositonの第1引数の3文字目がOなので、盤面の右上にOと表示します。
sample7.schの17行目でmoves関数を呼び出し、局面pの次に可能な局面のリストをlistに代入します。 19行目でprintPosList関数を呼び出し、listに含まれる局面をすべて表示します。
printPosList関数は4行目から9行目で定義されています。 5行目でisNil関数を呼び出し、listが空ならばreturnを呼び出し、戻ります。 listが空でなければ、6行目で先頭の値をfirst、8行目で残りの列をrestに代入します。 7行目でprintPosition関数を呼び出し、firstの局面を表示します。 9行目でprintPosList関数を再帰呼び出しし、restに含まれる局面を表示します。
理解を確かめるため、13行目の文字列を変更して動作を確認してみてください。
